# Verticals — current state

Poliedra has a shared practice-management core with dental-first history.

- Dental: most mature clinical vertical, including odontogram, implants, orthodontics, dental defaults, and terminology.
- Physio: concrete vertical with a dedicated patient tab, assessments, goals, treatment diary, exercise library, prescriptions, execution records, and a journey PDF. Its seven tables are the only backend schema currently versioned.
- Salus, Mind, Wellness, Fit, and Medical: currently represented mainly through branding, labels, defaults, and configuration rather than complete bounded clinical domains.
- “Other” allows a custom professional category.

Vertical conditions are presently distributed through components and utility configuration. No new vertical architecture is approved by POL-001. Future work must first distinguish shared core, vertical extension, entitlement, and authorization, with Product Owner-approved contracts.
